# Pages Directory

This directory contains top-level page components for each route in the application.

## Page Structure

Pages should follow these patterns:
- One page component per file
- Pages compose smaller components from the components directory
- Pages handle data fetching and state management
- Pages connect to global state and authentication
- Each page has a clear, single responsibility

## Key Pages

- **LoginPage**: User authentication
- **RegisterPage**: New user registration
- **DashboardPage**: Main user dashboard with overview
- **ChatPage**: AI agent conversation interface
- **ResearchPage**: Document search and knowledge retrieval
- **SchedulePage**: Calendar and scheduling interface
- **GuidancePage**: Personalized life guidance recommendations
- **ProfilePage**: User profile and settings
