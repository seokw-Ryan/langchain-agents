# Components Directory

This directory contains reusable UI components used throughout the application.

## Component Structure

Components should follow these patterns:
- One component per file
- Named exports for all components
- Component-specific styling in same directory
- Comprehensive PropTypes documentation
- Storybook stories for visual testing (optional)

## Key Components

- **ChatInterface**: Conversation UI for interacting with the AI agent
- **ScheduleViewer**: Calendar and task visualization
- **ResearchPanel**: Displays research results and citations
- **GuidanceCard**: Shows personalized guidance suggestions
- **DocumentUploader**: UI for adding documents to knowledge base
- **AuthForms**: Login and signup form components
- **Navigation**: App navigation and user menu
- **Layout**: Page layout templates
